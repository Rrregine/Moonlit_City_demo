# 🇬🇧 English

## 🎮 About the Game

*Moonlit City Demo* is a 2D Roguelike game prototype currently in development.

The story takes place in a dream world known as the **“Blind Zone”**, a place where dreams take physical form and forgotten things remain.

The protagonist fights within the Blind Zone, exploring memories forgotten by others while gradually uncovering the story hidden behind this mysterious world.

Eventually, the protagonist will be “rescued” by **Ling Bai** and leave the Blind Zone.

> *The Blind Zone is a place where forgotten things remain.*
